⚡ DevTracker.cs - Habit Tracker para Ciência da Computação

DevTracker.cs é um gerenciador de hábitos interativo, moderno e otimizado para estudantes de Ciência da Computação e Engenharia de Software (especialmente focado do 1º ao 3º período acadêmico).

O objetivo da aplicação é criar e manter a consistência de rotina exigida na área de tecnologia, equilibrando estudos teóricos, prática de código, projetos pessoais e saúde física/mental.

🚀 Funcionalidades Principais
🎨 Interface Dark Mode Dev: Design moderno inspirado em IDEs e terminais, com fontes monoespaçadas (Fira Code) e efeitos visuais em néon/glow.
🎓 Hábitos Padrão para CS: Já vem pré-carregado com 8 hábitos essenciais para iniciantes em programação (LeetCode, Git/GitHub, Estruturas de Dados, Pomodoro, Exercícios, etc.).
🏷️ Filtro por Categorias: Navegação rápida entre Todos, Acadêmico, Projetos Pessoais e Saúde & Bem-Estar.
📊 Dashboard & Gamificação:
Barra de progresso diária calculada em tempo real (%).
Contador de sequência de dias (Streak 🔥).
Títulos/Ranks dinâmicos do desenvolvedor (ex: Junior Dev, Code Ninja, Compiler Wizard).
Animação de confetes ao atingir 100% de conclusão no dia.
🔍 Busca em Tempo Real: Filtre hábitos pelo título ou descrição instantaneamente.
➕ CRUD Completo: Adicione novos hábitos personalizados, altere status e exclua tarefas.
💾 Persistência Total: Salva automaticamente todo o estado e histórico localmente via localStorage.
🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando apenas tecnologias web puras (Single File Mandate - sem necessidade de bundlers ou node_modules):
HTML5: Estruturação semântica.
Tailwind CSS (CDN): Estilização responsiva e utilitária com suporte a Dark Mode.
JavaScript (Vanilla): Lógica de estado, manipulação da DOM, cálculo de streaks e persistência em localStorage.
Lucide Icons: Pacote de ícones minimalistas.
Canvas Confetti: Efeitos visuais de celebração.

💻 Como Executar o Projeto
Como o projeto é construído em um único arquivo HTML independente, você pode executá-lo de duas formas simples:

Opção 1: Localmente
Clone este repositório:
git clone https://github.com/seu-usuario/dev-tracker-cs.git
NAVEGUE até a pasta do projeto:
cd dev-tracker-cs
Abra o arquivo index.html diretamente em qualquer navegador de sua preferência.

Opção 2: GitHub Pages
Você pode hospedar o projeto gratuitamente no GitHub Pages:
Vá nas Settings do seu repositório no GitHub.
Acesse a aba Pages no menu lateral.
Em Branch, selecione main (ou master) e salve.
O projeto estará no ar em poucos segundos!

💻 Resolver 1 problema de lógica / LeetCode (Acadêmico)

📖 Estudar 30 min da Linguagem Base (C/C++/Python) (Acadêmico - 1º Período)
🛠️ Avançar em Projeto Pessoal ou Portfólio (Projetos Pessoais)
⏱️ Pausas ativas com Técnica Pomodoro (Saúde)
